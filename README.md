# School Planner

A simple, clean online school planner that runs in your browser (Chrome and any modern browser).

## Features

- **Weekly Schedule** – Add your classes with day and time
- **Homework Tracker** – Keep track of assignments and due dates
- **Subjects** – List all your subjects
- Data is saved automatically in your browser (localStorage)
- Works offline after the first visit
- Mobile-friendly

## Live Demo

Once GitHub Pages is enabled, the app will be available at:

**https://ededwards2008-boop.github.io/school-planner/**

## How to use

1. Open the live link above (or open `index.html` locally)
2. Use the tabs to switch between Schedule, Homework and Subjects
3. Click the **+ Add** buttons to create new items
4. Edit or delete items anytime

## Tech

- Pure HTML, CSS & JavaScript
- No frameworks, no backend
- Data stored in the browser with `localStorage`

Made for students who want a simple planner without accounts or complexity.
